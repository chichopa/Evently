**Evently** — веб-платформа для поиска мероприятий и регистрации участников.

## О проекте

Проект направлен на создание удобного сервиса, с помощью которого пользователи смогут находить интересные мероприятия, просматривать информацию о них и регистрироваться для участия.

## Основные возможности

- Просмотр каталога мероприятий.
- Поиск по названию.
- Фильтрация по категориям и датам.
- Просмотр подробной информации о мероприятиях.
- Регистрация и авторизация пользователей.
- Просмотр списка зарегистрированных мероприятий.
